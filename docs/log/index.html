Decisions

Pure Scala
No dependency on the Java SDK, so no Kotlin runtime and no Jackson version pinning in Play apps.
Effects
Tagless-final F[_] on Cats Effect 3. Streams are fs2.Stream, the client is a Resource.
Codecs
Hand-written circe codecs through a small field DSL. Same source on Scala 2.13 and 3, no macros.
Forward compatibility
Unknown content blocks and events round-trip losslessly. Every object keeps unrecognised fields in extras.
Binary compatibility
SDK types use private constructors with withX builders, so a new API field never breaks compiled user code.
One type tree
Beta features are flags on the request, not a parallel set of Beta* types.
Sampling parameters
temperature, top_p and top_k are rejected on API version 2026-10-21, so they are not modeled.
Telemetry
Traces only in v1. Prompt and response content is exported only in opt-in content mode.

Log

2026-11-22

What is not done

No request has been sent to the real API: every test runs against fakes or a local server. Nothing is committed or published. Binary compatibility is proven at the source level only; MiMa starts comparing once a first version exists. Only the wire model compiles on Scala 3. There is no docs site, only the README, a Play guide and the compiled examples.

2026-11-22

M7 to M9 · Tracing, Batches, Files, Play

A traced agent run is one tree: the runner, each request, each tool call, and any span the tool opens itself. With default settings no prompt or reply text reaches a span, and a test asserts it. The default artifact has no Kotlin and no Jackson on its classpath. The wire model compiles and passes its tests on Scala 3 unchanged, and CI now checks that.

2026-11-22

M6 · Tool runner

Tools are functions from a case class to an effect. Calls of one turn run concurrently and their results return in order in one message: three tools sleeping 300, 100 and 200 ms finish in 300 ms. A refusal, a token limit or an operator abort ends a run as a value, not an exception.

2026-11-22

M5 · Structured outputs

messages.parse[A] works for any case class with no instance to declare. One derivation yields the JSON Schema, the decoder and the encoder, so they cannot disagree. With Play JSON, PlaySchema.derived[A] pairs that schema with your Format. A planned blanket import for Play was dropped: it also matched Format[String] and broke derivation from the inside.

2026-11-22

M2 to M4 · Client, retries, streaming

Real sockets exposed what the in-memory fake could not: Ember spends up to 5 seconds draining a half-read response before closing it, so cancelling a stream stalled. Abandoned streams now close at once, and completed ones are read to the end of the body so the connection is reused for the next turn. The non-streaming timeout stays at a flat 10 minutes instead of shrinking with max_tokens.

2026-11-22

M0 and M1 · Build and wire model

A compile-time test proves the binary-compatibility pattern: constructors, copy and positional patterns of SDK types do not compile for users, withX builders do. A round-trip law covers the wire model, including block types and fields the SDK has never seen.

Three logo directions drawn. Working pick is the cat-eared tile holding an A: it stays legible at 16 px and reads as Cats plus the API it wraps. Mark saved to docs/assets.

2026-11-22

Research

The official API has 382 endpoints and no public OpenAPI spec, which rules out code generation. No existing Scala client is native to Cats Effect with derived strict schemas, a tool runner and otel4s tracing.
